# WorkLink API

Backend do WorkLink.

## Stack

- Java 21
- Spring Boot
- Maven

## Comandos esperados

```bash
mvn test
mvn spring-boot:run
```

## Observacao

O projeto exige JDK 21. Executar build com JDK inferior deve falhar e ser tratado como lacuna de ambiente, nao como motivo para reduzir a versao alvo.
