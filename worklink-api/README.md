# WorkLink API

Backend do WorkLink.

## Stack

- Java 21
- Spring Boot
- Maven

## Comandos esperados

```bash
make backend-unit-test
make backend-integration-test
make backend-test
```

## Observacao

O projeto exige JDK 21. As validacoes devem rodar em Docker pelo `compose.yml`, sem exigir JDK 21 ou Maven instalados
diretamente na maquina.
