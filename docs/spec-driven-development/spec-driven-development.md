# Spec Driven Development — WorkLink

Este arquivo e o indice dos padroes obrigatorios usados pelos agentes antes de implementar qualquer historia.

## Documentos normativos

- `docs/spec-driven-development/codigo-limpo.md`
- `docs/spec-driven-development/padroes-de-testes.md`
- `docs/spec-driven-development/padrões-de-projeto-e-design-de-codigo.md`

## Regra de uso

Toda demanda deve partir dos requisitos da historia e copiar para o plano de execucao os criterios relevantes destes documentos.

O plano deve deixar explicito:

- regras de codigo limpo aplicaveis;
- estrategia de testes;
- criterios de arquitetura e design;
- riscos de acoplamento com framework, infraestrutura ou dependencias externas;
- gates de QA, SRE, seguranca, arquitetura e revisao final quando aplicaveis.
