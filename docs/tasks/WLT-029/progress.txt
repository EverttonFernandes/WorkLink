Falha observada:

- Não há URL de backend de homologação configurada no GitHub Actions.
- Não há allowlist `WORKLINK_HOMOLOGATION_ALLOWED_HOSTS` configurada no GitHub Actions.
- Não há secrets de assinatura Android de homologação configurados no GitHub Actions.
- Não há fingerprint `WORKLINK_ANDROID_HOMOLOGATION_CERT_SHA256` configurado no GitHub Actions.
- Flutter não está disponível diretamente no WSL atual; Docker Desktop está acessível via `docker.exe`.

Hipótese de correção:

- Rota preferencial: usar workflow manual com input `homologation_api_base_url` apontando para backend HTTPS acessível pelo celular, com allowlist, signing secrets e fingerprint configurados.
- Rota alternativa para teste rápido local: subir `make homologation-local-up` e gerar APK debug com `MOBILE_LOCAL_API_BASE_URL=http://<ip-da-maquina>:8080 make mobile-android-local-fullstack-candidate`. Esse APK não é promovível.

Ação tomada:

- Pipeline ajustada previamente para aceitar URL por variable, secret ou input manual.
- Pipeline endurecida para exigir assinatura de homologação e validar URL antes de gerar artifact promovível.
- State machine do Ralph Loop criada para rastrear o fechamento.

Resultado:

- WLT-029 permanece em execução até existir APK full-stack versionado e validado.
