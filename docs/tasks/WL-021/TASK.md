# WL-021 — Solicitação de feedback pós-contato

## História

Como usuário cliente, quero receber uma solicitação clara de feedback depois que eu iniciar contato com um profissional, para responder sem depender de lembrar manualmente desse passo.

## Valor

Torna a coleta de feedback pós-contato ativa, rastreável e mais previsível para a plataforma.

## Critérios de aceite

- Contato iniciado gera pendência de feedback pós-contato.
- App exibe solicitação quando houver pendência elegível.
- Usuário consegue responder o feedback pela solicitação.
- Sistema não solicita feedback duplicado para contato já respondido.
- Solicitação dispensada fica registrada para evitar insistência imediata.
