# WL-019 — Portfólio e fotos de trabalhos do profissional

## História

Como profissional, quero associar fotos ou arquivos de portfólio ao meu perfil para que clientes avaliem exemplos reais
do meu trabalho.

## Valor

Melhora a confiança do cliente no perfil público sem criar promessa de garantia de qualidade ou KYC avançado.

## Critérios de aceite

- Profissional consegue adicionar item de portfólio ou foto de trabalho.
- Sistema valida tipo e tamanho do arquivo conforme política de storage.
- Perfil público exibe itens de portfólio ativos.
- Dados sensíveis não são expostos nos metadados públicos.
- Fluxo usa storage seguro já existente.
