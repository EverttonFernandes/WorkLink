# WL-018 — Verificação do telefone do profissional

## História

Como profissional, quero verificar meu telefone/WhatsApp para que clientes identifiquem que meu contato foi confirmado.

## Valor

Fortalece a confiança progressiva do WorkLink V1 sem prometer garantia de qualidade do serviço.

## Critérios de aceite

- Profissional consegue solicitar verificação do telefone/WhatsApp.
- Sistema confirma o telefone por código compatível com V1.
- Status de telefone verificado é persistido.
- Listagem e perfil exibem badge apenas quando o telefone foi confirmado.
- Profissional sem confirmação não recebe badge de telefone verificado.
- Ação sensível exige autenticação, ownership e auditoria.
