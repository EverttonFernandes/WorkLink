# WL-020 — Profissionais salvos e preferências persistentes do cliente

## História

Como usuário cliente autenticado, quero salvar profissionais e persistir preferências básicas para manter meus interesses entre sessões.

## Valor

Torna o perfil do cliente útil de forma persistente, reduzindo retrabalho de busca e mantendo continuidade entre acessos.

## Critérios de aceite

- Usuário autenticado consegue salvar profissional.
- Usuário autenticado consegue remover profissional salvo.
- Perfil do usuário lista profissionais salvos a partir do backend.
- Preferências básicas são persistidas e recarregadas entre sessões.
- Usuário não autenticado não altera dados de perfil.
